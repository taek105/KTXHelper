사용 방법
  1. 로그인
    코레일 회원번호·비밀번호를 입력하세요. 일반 Chrome 창에서 자동으로 로그인합니다.
  2. 여정 선택
    출발역·도착역, 예매 날짜와 출발 시간을 선택하세요.
  3. 스케줄 조회
    “스케줄 조회” 버튼을 누르면 Chrome 창에서 로그인하고 열차 목록을 불러옵니다.
  4. 열차 선택
    원하는 열차 행을 클릭하면 파란색으로 강조됩니다.
  5. 매크로 실행
    선택이 완료되면 “매크로 실행” 버튼을 누르세요. 새 Chrome 창에서 자동 로그인 후 예약을 시작합니다.
